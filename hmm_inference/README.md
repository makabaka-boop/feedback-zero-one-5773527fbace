# 精确隐马尔可夫路径推断作业

从零用 Python 实现的后端推断作业：在带静默（`null`）自环/环、平行边、
立即失败余量和不终止质量的概率路径模型上，精确计算

* 成功路径权重之和 **likelihood**；
* 条件于成功的**每条转换期望遍历次数**（不是“至少经过一次”的概率）；
* 权重最大的成功路径及其权重（含平局规则）。

所有数值均为约分后的正分母分数 `p/q`（基于 `fractions.Fraction`），核心的
静默环求和与条件推断自行实现（分数高斯-若尔当消元），不截断静默步数，
不终止/失败质量绝不分摊给成功路径。

## 目录结构

```
hmm_infer.py                    入口与全部实现（校验 + 推断 + 最优路径）
test_hmm_infer.py               31 个手算验收单元测试（含 CLI 测试）
test_bruteforce_crosscheck.py   独立暴力枚举交叉验证（随机 + 手工环模型）
fixtures/                       手算用例的输入 JSON
```

## 运行方式

```bash
# 结果打印到标准输出
python3 -I hmm_infer.py fixtures/canonical_loop.json

# 同时写入输出文件；仅在整次作业成功后才替换该文件
python3 -I hmm_infer.py fixtures/canonical_loop.json -o result.json

# 手算验收
python3 -I test_hmm_infer.py

# 暴力枚举交叉验证（约 550 个模型，含静默环截断区间校验）
python3 -I test_bruteforce_crosscheck.py
```

`-I` 以隔离模式运行，避免当前目录/环境中的同名模块被意外导入。

## 输入格式

```json
{
  "states": ["s", "f"],
  "initial": "s",
  "final": ["f"],
  "transitions": [
    {"id": "loop",  "source": "s", "target": "s",
     "label": null, "prob": "1/2"},
    {"id": "exitA", "source": "s", "target": "f",
     "label": "A",  "prob": "1/2"}
  ],
  "observations": ["A"]
}
```

规则：

* 状态 id 与转换 id 均为唯一、非空的 ASCII 字母数字串，所有引用必须存在；
* `prob` 为 `p/q` 字符串，`p` 为整数、`q` 为正整数，取值落在 `[0,1]`；
* 非终态出边概率和 `<= 1`，余量是立即失败；终态无出边；允许环与平行边；
* `label` 为非空字符串或 `null`；`null` 不产生观测，其余标签按序产生一项；
* 观测数组元素为非空字符串，数组可为空；
* 成功路径必须有限、恰好产生全部观测并到达终态；不终止、失败、标签
  多余或缺失均不成功。

## 输出格式

似然为正时：

```json
{
  "likelihood": "1/1",
  "status": "success",
  "expected_visits": [
    {"transition_id": "exitA", "expected_visits": "1/1"},
    {"transition_id": "loop",  "expected_visits": "1/1"}
  ],
  "best_path": {"transition_ids": ["exitA"], "weight": "1/2"}
}
```

* `expected_visits` 按转换 id 排序，保留零项（`"0/1"`）；
* `best_path` 取权重最大者；平局先取转换数最少，再取完整转换 id 序列的
  ASCII 字典序最小者。

似然为零时**只**返回：

```json
{"likelihood": "0/1", "status": "impossible"}
```

非法输入整次拒绝，标准输出为空，退出码 `2`，标准错误给出定位路径：

```json
{"error": "prob '3/2' is outside [0, 1]",
 "path": "$.transitions[0].prob"}
```

使用 `-o` 时，只有完全成功才会替换输出文件；拒绝时原文件保持不变。

## 算法

### 静默环的精确求和（不截断）

把静默转换（`label == null`）的概率聚成矩阵 `Q`，带标签转换单独处理。
在固定观测层上，静默移动服从 `(I - Q)` 线性系统；由于 `Q` 是次随机矩阵，
`(I - Q)^{-1} = I + Q + Q^2 + ...` 恰好是所有（无限多条）静默游走的
几何级数和，自环、多状态环都被精确消去，无需设定步数上限。

存在概率 1 的封闭静默环时，`I - Q` 全局奇异。先用反向可达性找出
**坏区域 B**：只能永远静默移动（或失败）、永远到不了标签边或终态的状态。
在 B 上求解无意义，将其从线性系统中剔除；不终止质量因此自然不会进入
任何成功路径的计算，也不会被分摊。好区域上的 `I - Q` 严格可逆。

### 后向 / 前向

* 后向 `f[k][u]`：在第 `k` 层位于状态 `u` 时，成功后缀的总权重。基底层
  `f[n]` 不是简单的终态指示量，而是它在静默图上的闭包——这正确覆盖了
  空观测序列以及最后一个标签之后的静默收尾；
* 前向维护两个量：`a[k]`（经第 k 条带标签边到达的质量）与
  `ap[k] = (I-Q)^{T,-1} a[k]`（随后静默移动后的质量）。进入坏区域的
  质量被丢弃。前向终态总量与后向似然做精确一致性断言。

### 条件期望遍历次数

对转换 `e = (u -> v, 概率 p)`：

* 静默边，在第 k 层：`ap[k][u] * p * f[k][v]`，对所有层求和；
* 带标签边，仅在观测匹配的层 k：`ap[k][u] * p * f[k+1][v]`，
  重复观测时对所有匹配层求和。

求和得到的是“成功路径权重 × 该边遍历次数”的总和（自环的多次遍历通过
几何级数自动计入），除以似然即条件期望，故它是真正的期望计数而非
“至少经过一次”的概率。

### 最优路径

在静默图上做 max-plus Floyd–Warshall 闭包，候选按
`(权重降序, 边数升序, id 序列 ASCII 升序)` 比较。静默环不会出现在最优
路径中：删去一个静默环得到更短、权重不降低的合法路径（概率 1 的环
只增加边数）。随后按观测层做动态规划，每一步枚举“静默前缀 + 匹配标签边
+ 后缀”。

## 手算验收摘要

`fixtures/` 中的关键用例（完整断言见 `test_hmm_infer.py`）：

| 用例 | 手算结果 |
| --- | --- |
| `canonical_loop` 1/2 静默自环 + 1/2 标签 A 出口，obs [A] | L=1；loop、exitA 条件期望各 1；最优 [exitA] 权重 1/2 |
| `closed_silent_loop` 概率 1 的封闭静默环 | `impossible`，不终止质量不分摊 |
| `empty_obs` 静默环 2/3 + 静默出口 1/3，obs [] | L=1；环期望 2、出口期望 1；最优 [go] 权重 1/3 |
| `zero_prob_edge` 0/1 边与 1/2 边平行 | L=1/2；零边期望保留为 0/1 |
| `tie_length` 两条权重 1/2 的路径，一长一短 | 边数少者胜 |
| `tie_lex` 平行边 ea/ez 同权同长度 | id 序列 ASCII 小者 `ea` 胜 |
| `failure_mass` 每步 1/3 失败余量 | L=1/2；失败与成功各占一半，余量未被分摊 |
| 双层静默环（obs [A,B]） | L=1；四条边条件期望各 1 |
| 菱形分支 | L=3/4；期望随路径权重 1/3 与 2/3 分化，证明是期望而非访问概率 |

此外 `test_bruteforce_crosscheck.py` 用完全独立的记忆化路径枚举核对：
静默 DAG 模型上做分数级精确比对；含环模型上用截断前沿给出严格区间
`枚举值 <= 精确值 <= 枚举值 + 前沿质量`，且枚举深度增加时单调收敛
（实测以几何速度逼近），最优路径因其无环性仍做精确比对。
